# EJEE 桌宠

一只橘色小金鱼桌宠：会撒娇、会生气、会晕车、会睡觉，陪你在 Windows 桌面上干活。

## 功能

- **9 种情绪状态**：待机 / 开心 / 生气 / 惊讶 / 傲娇（连摸会躲）/ 晕车（拖到边缘会晕）/ 调皮（喷橘子汁）/ 睡眠（5 分钟不理就睡）/ 饥饿
- **弹簧物理动画**：Q 弹的 squash & stretch、拖拽惯性滑行撞墙反弹、尾巴轻摆、视线跟随鼠标
- **喂食互动**：点身体喂面包，吃饱会鼓肚打嗝；也可以「拿起面包」拖到它嘴边喂
- **主题气泡**：每种状态有配套的奶油云 / 爆炸 / 圆泡泡 / Zzz 气泡，幼圆字体
- **番茄钟**：开始自选时长（1~180 分钟），桌宠陪你专注，到点撒花提醒
- **穿透模式**：鼠标点击穿透到桌面，右键仍可唤出菜单；Shift + 滚轮缩放
- **陪伴档案**：记录相识天数、喂食次数、摸头次数，久别重逢会打招呼
- **位置记忆 + 开机自启**：记住上次待在屏幕哪个角落，可随系统启动

## 使用方法

### 方式一：直接用（推荐）

去 [Releases](../../releases) 下载 `EJEE.exe`，双击即用，无需安装 Python。

### 方式二：源码运行

```bash
# 需要 Python 3.10+
pip install -r requirements.txt   # PySide6 + Pillow
python ejee_pet.py
```

资源文件在 `assets/` 目录，与 `ejee_pet.py` 保持同级即可。

### 方式三：自己打包 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean EJEE.spec
# 成品在 dist/EJEE.exe
```

## 操作方式

| 操作 | 效果 |
|---|---|
| 左键单击身体 | 喂面包（双击重置大小） |
| 拖拽 | 拎起来走，松手惯性滑行 |
| 右键 | 菜单：拿起面包 / 陪伴档案 / 开始番茄钟 / 穿透模式 / 尺寸 / 退出 |
| Shift + 滚轮 | 缩放（0.5x ~ 3.0x），双击重置 1.0x |
| 托盘图标 | 显示/隐藏、开机自启、重置大小 |

## 环境要求

- Windows 10/11
- Python 3.10+（仅源码运行需要）
- 依赖：PySide6 >= 6.12、Pillow >= 12

## 开发

`sim_round38.py` 是离屏回归仿真（120 条断言），改动渲染/状态机后跑一遍确认无回归：

```bash
python sim_round38.py
```

`python ejee_pet.py --shot` 可离屏渲染各状态预览图到 `previews/` 目录，供校准用。
